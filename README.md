# MotMan, les mots fléchés en duel

**▶ Jouer : [www.doctox.fr/motman](https://www.doctox.fr/motman/)** · [Découvrir le jeu](https://www.doctox.fr/motman/mots-fleches-en-duel/)

Deux joueurs partagent la même grille de mots fléchés : chaque lettre juste colore une case au nom de celui qui l’a trouvée, et le meilleur score l’emporte. Défi du jour à thème, parties entre amis, mode classé. Gratuit, dans le navigateur sur téléphone, tablette et ordinateur.

Ce dépôt contient le code du jeu (React, Vite, Supabase, Capacitor). Les grilles et leurs solutions n’y figurent pas.
